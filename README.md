# 三维果岭坡度查看器

手机与电脑浏览器均可打开的果岭坡度 / 推杆线路工具。养护组每周测得的高程点从
CSV 导入，经手写 Delaunay 三角剖分构建 TIN 地形，在三维场景中显示下坡箭头、
等高线与三档力度滚动线，并自动解算瞄准点的高坡偏移。

## 功能

- **CSV 高程导入**：支持带表头（中英文列名）或纯 `x,y,z` 三列，逗号/分号/Tab 分隔，坏行自动跳过
- **手写 Delaunay**：Bowyer–Watson 增量插入，含超级三角形、外接圆判定、邻接表与边界边重建（`src/lib/delaunay.ts`）
- **TIN 地形查询**：空间哈希定位三角形、重心坐标插值、解析坡度/法向、等值线提取（`src/lib/terrain.ts`）
- **下坡箭头**：实例化锥体，指向海拔降低方向，颜色随坡度变化
- **瞄准解算**：网格定号 + 二分搜索发射方向，输出瞄准点相对球-洞直线的横向偏移（米）及是否偏高坡侧（`src/lib/aim.ts`）
- **三档滚动线**：轻/中/重力度共用同一发射方向；滚出果岭后切换长草摩擦继续积分，虚线显示越界段
- **Stimp → 摩擦**：`μ = v₀²/(2gS)`，修剪高度经指数模型折算等效读数（`src/lib/friction.ts`）
- **时刻光照**：NOAA 太阳算法驱动平行光方位/高度与色温，PCF 软阴影贴图
- **截图**：WebGL 画面 + Canvas2D 图例（坡度色带、力度图例、瞄准读数、比例尺、时间戳）导出 PNG
- **触屏交互**：单指拖动球位/洞位（rAF 节流），空白处拖动旋转，双指/滚轮缩放

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建（dist/）
npm run preview    # 预览构建产物
npm test           # node:test 全部 23 个用例
npm run gen-samples  # 重新生成演示 CSV
```

演示数据：`public/samples/green-demo.csv`（25m×25m、1m 间距、625 点）。
导入自己的 CSV 后界面操作与演示完全一致。

## 物理模型说明

- 坡面约束 `z=h(x,y)` 下拉格朗日推导：水平切向重力 `-g·∇h/(1+|∇h|²)`，
  滚动阻力 `-μg·v/(|v|·(1+|∇h|²))`，平地退化为标准匀减速 `a=-μg`
- 积分：固定步长 8ms 欧拉，25Hz 采样输出
- 洞杯：线段-圆相交 + 捕获速度 `v*=√(K·g·r)`（K=1.63），高速撞洞缘不捕获
- 越界：沿用最后所在三角形坡度、切换长草摩擦（默认 μ=0.25）继续积分直至停住
