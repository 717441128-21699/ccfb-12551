# 果岭坡度三维查看

给球场养护组、球童和会员用的果岭坡度可视化工具。每周测量的高程点 CSV 导入后,
自动生成三维果岭、坡度着色、下坡箭头、等高线和推杆滚动模拟。手机、电脑浏览器都能开。

## 运行

```bash
npm install
npm run dev      # 开发(手机同一局域网可访问,已开 host)
npm run build    # 生产构建 → dist/
npm test         # 解析坡面精度验证
```

## 页面

| 页面 | 功能 |
|------|------|
| 球场 | 果岭列表、导入 CSV、下载示例 CSV |
| 测量数据 | 高程点预览、三角剖分统计、测试果岭精度验证 |
| 三维果岭 | 坡度着色 + 下坡箭头 + 等高线(间距可调)+ 时刻光照/阴影 + 截图(带图例) |
| 推杆线 | 点球位、点洞位,模拟推杆滚动轨迹,显示进洞/侧移/距离 |
| 草况设置 | 斯坦普表读数 → 摩擦系数换算,修剪高度/湿度修正,快捷预设 |

## 技术要点

- **Delaunay 三角剖分**:手写 Bowyer-Watson 增量算法(`src/delaunay.ts`)
- **坡度**:每个三角形平面梯度,顶点处按面积加权平均;按 0/2/4/6% 绿→黄→橙→红着色
- **等高线**:行进三角形法(marching triangles),间距 0.05–0.5 m 可调
- **推杆物理**:半隐式欧拉积分,重力沿曲面分量 + 滚动摩擦 μ·g;进洞判定考虑过洞速度
- **斯坦普表换算**:μ = v₀²/(2·g·S),v₀ = 1.83 m/s(USGA 标准出槽速度)
- **光照**:太阳位置随时刻(6–19 时)变化,PCF 软阴影贴图
- **触屏**:OrbitControls 单指旋转、双指缩放/平移

## 精度验证

测试果岭由解析曲面 `z = 0.022x + 0.014y + 0.05·sin(2πx/12)·cos(2πy/12)` 生成,
坡度真值有解析式。重建后逐三角形对比:

- 最大偏差 **0.804 个百分点**(要求 ≤ 2)
- 平均偏差 0.161 个百分点

复验:`npm test`。注意测量时**边界要加密测点**(本工具测试果岭采用边界环),
否则椭圆裁切产生的狭长三角形会把坡度误差放大到 5–10 个百分点。
